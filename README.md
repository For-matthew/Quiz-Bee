# CWS Quiz Bee (React + Vite)

Proyekto para sa Children's Worship Service (CWS) Quiz Bee game na may jumbled letters mechanics at custom CWS theme.

## Paano Patakbuhin:

1. Buksan ang folder sa **VS Code**.
2. Buksan ang Terminal (`Ctrl + \`` o `Terminal > New Terminal`).
3. I-install ang dependencies:
   ```bash
   npm install
   ```
4. Simulan ang development server:
   ```bash
   npm run dev
   ```
5. Buksan ang link na ipapakita (kadalasang `http://localhost:5173`).
